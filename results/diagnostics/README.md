# Diagnostics (사후 탐색) — 크게 틀린 가려진 손가락이 왜 물체에서 멀리 예측되는가
기존 H1 판정(기하 검사로 검출 불가)에는 영향이 없다. 기준은 실행 전에 PROTOCOL.md "Diagnostics"에 고정.

## 준비와 재현
- 기존 pred.npz에 MANO 파라미터·카메라·2D 관절이 없어 같은 설정으로 재추론 → repro_*/pred.npz.
- 재추론 예측은 기존과 비트 단위로 동일(관절·정점 최대 차이 0.0).
- AUROC 표 재현: DexYCB 숫자 항목 520개, HO-Cap 634개 모두 기존과 차이 0.0 (기준 0.001 이내 충족).

## 보조 수치
- (a)는 보이는 손가락에서도 같음: B2 보임 큰 오류의 손목 평행이동 설명 0.87(HO-Cap), 0.92(DexYCB). 가림에만 있는 원인이 아님.
- B1(손바닥 정렬 후) 물체 가림 큰 오류 손끝: 물체에서 떠 있음(>+5mm) 64% [51, 75](HO-Cap), 74% [44, 85](DexYCB).
  예측 손끝의 물체 부호 거리 중앙값 9.8mm vs 정답 0.5mm(HO-Cap), 19.3mm vs 8.8mm(DexYCB).
- 손바닥 중심→손끝 거리(예측−정답): HO-Cap 물체 가림 큰 오류 +4.3mm [3.0, 5.8], 작은 오류도 +3.9mm → 체계적 차이이지 큰 오류 특이 아님.
  DexYCB +8.4mm [−0.3, 16.1].

## 결론
손 전체 깊이 오차(a)는 실사용 정렬(B2)에서 손끝 오차의 대부분(81–87%)을 설명하지만, 보이는 손가락에서도 같은 크기로 나타나
가림 특이 원인은 아니다. 손바닥을 정답에 맞춘 뒤(B1)에도 가려진 큰 오류 손끝의 64–74%가 물체에서 떠 있으며, 이 남은 오류는
주로 이미지 평면 방향(시선 성분 0.33–0.47)이어서 손가락 깊이(b)로 설명되지 않고, 평균 자세로 물러남(c)도 지지되지 않았다.
"더 펴짐"은 DexYCB에서만 나타났다. 따라서 B2의 원인은 (a), B1에 남는 "떠 있음"은 미리 정한 원인으로는 (d) 해당 없음.
다음 실험: (a) → 물체를 기준으로 손 전체 평행이동만 보정 (Diagnostics 2의 C/E2).
