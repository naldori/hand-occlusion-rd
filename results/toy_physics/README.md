# 정적 평형 검사 간이 검증 (2026-11-02)

장난감 모델: 원기둥 물체(r=35mm, 0.3kg), 점 접촉 + 마찰 피라미드(8면), 손가락당 최대 법선력 15N,
중력 방향은 무작위 200개(단일 이미지에서는 알 수 없으므로). 설정은 실행 전에 고정.

- check_equilibrium.py → results.json
  - E1: LP 1회(접촉 5개) 약 1.1ms (scipy HiGHS, CPU)
  - E2: 무작위 접촉 k개에서 평형이 존재하는 비율 (mu 0.3/0.5/0.8)
    k=3: 0.03/0.16/0.46, k=5: 0.50/0.71/0.83
  - E3: 엄지+네 손가락 파지에서 엄지가 아닌 손가락 1개 오류 → 평형 존재 비율
    미끄러짐 5–40mm, 1–20mm 들림, 손가락 누락, 엄지 쪽으로 이동: 모두 1.0 (검출 0%)
    엄지 누락만 0.0 (검출)
- score_sensitivity.py → score_sensitivity.json
  - 연속 점수(평형에 필요한 최대 손가락 힘)의 오류/정답 비율 중앙값:
    미끄러짐 40mm 1.00 (최대 1.05), 누락 1.04, 엄지 쪽 이동 0.66 (틀린 자세가 더 좋은 점수)

한계: 점 접촉, 단순 형상, 관절 토크(τ=Jᵀf) 검사와 관통/거리 검사는 포함하지 않음.
